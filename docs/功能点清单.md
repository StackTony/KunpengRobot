# 鲲鹏运维平台 · 客户功能点清单

> 记录时间：2026-10-10 ｜ 状态：已确认需求基线

## 核心功能点（客户确认）

| # | 功能点 | 说明 | 优先级 |
|---|--------|------|--------|
| 1 | 用户权限控制 | 普通用户 / 管理员两种角色，JWT + RBAC | 高 |
| 2 | 故障诊断日志分析 | 被动上传日志包（一键收集后上传），并发分析，支持后续扩展不同日志格式 | 高 |
| 3 | 智能巡检 | 规则引擎优先匹配，结合 LLM 智能化总结；可扩展其他能力 | 高 |
| 4 | 并发上传 + 实时流式输出 | 用户规模约 1k 人，并发上传约 100+ QPS，后续可能增长 | 高 |
| 5 | 巡检规则管理 | 管理员可对日志巡检规则增删改查，规则版本化热加载 | 高 |
| 6 | 性能数据图表 | 图表数据持久保存，切换页签 / 刷新页面不丢失 | 中 |

## 硬性约束

- **日志来源**：被动上传模式（用户在目标服务器一键收集日志包后上传），不做主动采集
- **部署环境**：ARM（鲲鹏）/ x86 双架构，Linux 和 Windows 均需支持，Web 端访问
- **技术栈**：Python 实现；部署方式需提供裸机（systemd / NSSM）和 Docker Compose 两套
- **UI 风格**：简约大气
- **智能能力**：规则引擎优先 + LLM 总结混合模式（LLM 未配置时降级纯规则）
